# DgmCraft

Воксельная песочница в духе Minecraft — играбельный прототип на **Three.js + Vite**, работает в браузере.

## Возможности

- **Процедурно-генерируемый воксельный мир** на шуме симплекса (биомы: трава, песок, камень, вода, деревья).
- **Стриминг чанков** 16×64×16 вокруг игрока (рендер по нужным граням, отдельные меши для прозрачных блоков).
- **От первого лица**: WASD + мышь, прыжок, гравитация, AABB-коллизия по осям, плавание над землёй.
- **Ломание/постановка блоков** — DDA-рейкаст по воксельной сетке, подсветка целевого куба.
- **Хотбар** на 9 слотов (трава, доски, камень, песок, кирпич, стекло, светящийся камень, RS-источник, RS-провод). Колесо мыши и цифры 1–9 переключают слоты.
- **Три режима**:
  - **Творчество** — полёт, бесконечные блоки, без HP.
  - **Выживание** — гравитация, HP, респаун, нет полёта.
  - **Education** — отдельная панель с описанием каждого блока, на который наведено перекрестие.
- **Редстоун-логика**: блоки «источник» (вкл/выкл клавишей **R**), «провод» (BFS-распространение сигнала до 32 блоков) и «лампа» (включается рядом с проводом/источником, меняет блок и эмиссию).
- **Цикл день/ночь**: вращающееся солнце, луна, динамическая интенсивность света и цвет неба, время суток в HUD.
- **Сохранение/загрузка** в `localStorage` (сид мира + изменения + источники сигнала + позиция игрока + хотбар).
- HUD с режимом, временем, HP-баром (в выживании), панелью Education и подсказкой по управлению в меню.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD | Движение |
| Пробел | Прыжок / лететь вверх |
| Shift | Присесть / лететь вниз |
| F | Переключить полёт (творчество/education) |
| ЛКМ | Сломать блок |
| ПКМ | Поставить блок |
| Колесо / 1–9 | Выбрать блок в хотбаре |
| R | Переключить редстоун-источник |
| P | Сохранить мир |
| Esc | Меню паузы |

## Установка и запуск

```bash
npm install
npm run dev      # дев-сервер на http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # запуск собранной версии
npm run lint     # линт
```

## Структура

```
src/
  main.js      — точка входа, рендер-цикл, UI и сохранения
  world.js     — чанки, генерация, мешинг, рейкаст, AABB
  player.js    — контроллер от первого лица + физика
  redstone.js  — простая редстоун-симуляция
  blocks.js    — реестр блоков (id, цвета, твёрдость, edu-описание)
  style.css    — HUD и меню
```
