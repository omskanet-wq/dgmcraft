# DgmCraft

DgmCraft — браузерная воксельная песочница в духе Minecraft. Базой служит однофайловый прототип `mine.html` (Three.js r128), поверх него добавлены:

- три режима игры: **Survival**, **Creative**, **Education** (с описаниями каждого блока в HUD);
- мини-«редстоун»: блоки `Source / Wire / Lamp` и BFS-симуляция сигнала, источник переключается клавишей **R** или кнопкой `R` в тач-UI;
- сохранение и загрузка мира в `localStorage` (клавиши **P/L** или команды `/save` / `/load`, кнопка «Load saved world» в меню);
- PWA: `manifest.webmanifest`, service worker и иконки — игру можно установить как приложение на Android и iOS и играть офлайн;
- тач-управление: виртуальный джойстик слева, look-зона справа, кнопки `Jump / Break / Place / Inv / Chat / R / Fly / Esc`;
- responsive HUD под маленькие экраны.

## Файлы

- `index.html` — собранная игра DgmCraft (mine.html + DgmCraft-расширения).
- `mine.html` — оригинальный прототип-источник (без правок), оставлен для справки.
- `manifest.webmanifest`, `service-worker.js`, `icons/` — PWA-обвязка.

## Запуск

Любой статический сервер:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080/
```

PWA-функции (установка, офлайн) работают только при загрузке через HTTP(S), не через `file://`.

## Управление

### Десктоп
- `WASD` — движение, `Space` — прыжок, двойной `Space` в Creative — полёт
- `LMB` — ломать блок, `RMB` — поставить блок
- `Shift` — спускаться при полёте, `Ctrl` — спринт
- `1..9` — слот хотбара, колесо мыши — переключение слотов
- `E` — инвентарь, `T` или `/` — чат, `F3` — отладка
- `R` — переключить редстоун-источник под прицелом, `P` — сохранить мир, `L` — загрузить
- `F` — переключить полёт, `C` — зум, `Esc` — пауза/меню

### Мобильные / тач
Все десктоп-действия продублированы кнопками. Левый джойстик — движение, правая часть экрана — обзор камеры. Тап по правой зоне без перемещения = поставить блок, кнопка `Break` (удержание) — ломать.

### Чат-команды
- `/gamemode 0|1|2` — Survival / Creative / Education
- `/save`, `/load` — сохранение/загрузка мира
- `/give <BLOCK> [count]` — выдать блок (Creative/Education)
- `/time set <0-24000|day|night>` — время суток
- `/tp x y z` — телепорт
- `/fly` — переключить полёт
- `/help` — список команд

## Разработка

Файл `index.html` — самодостаточный, никаких бандлеров не требуется. Three.js подгружается с CDN. Для полной офлайн-игры пользователь устанавливает PWA.
